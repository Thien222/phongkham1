=============================================
  HƯỚNG DẪN SỬ DỤNG - PHÒNG KHÁM MẮT
=============================================

PHIÊN BẢN PORTABLE - Chạy 1 file BAT duy nhất

=============================================
CÁC TÍNH NĂNG MỚI
=============================================

1. TIẾP TÂN:
   - Thêm bệnh nhân với thị lực ban đầu (mắt phải/trái)
   - Checkbox "Có đeo kính"
   - Lý do đến khám
   - Ghi chú
   - Mã số thứ tự tự động (STT001, STT002, ...) - Reset mỗi ngày

2. KHÚC XẠ:
   - 3 loại khúc xạ:
     + Khúc xạ khách quan (Skiascopy)
     + Khúc xạ chủ quan (Subjective)
     + Kính điều chỉnh (Prescription)
   - Thêm độ ADD (cho kính đa tròng)
   - Khoảng cách đồng tử (PD)
   - Loại kính: Đa tròng/2 tròng/Đơn tròng

3. KHO HÀNG:
   - Phân loại tròng kính: Đơn tròng/2 tròng/Đa tròng
   - Filter theo loại tròng
   - Độ ADD cho tròng đặc biệt

4. DASHBOARD:
   - Hiển thị số lượng bệnh nhân (không hiển thị doanh thu)
   - Bệnh nhân khúc xạ hôm nay
   - Khám bệnh hôm nay
   - Hóa đơn kính hôm nay

=============================================
CÁCH CHẠY PHẦN MỀM
=============================================

1. Double-click vào file "START.bat"
2. Chờ server khởi động (cửa sổ đen xuất hiện)
3. Mở trình duyệt và truy cập: http://localhost:4000
4. Đăng nhập (nếu cần)

LƯU Ý:
- KHÔNG TẮT cửa sổ đen (đó là server đang chạy)
- Để tắt phần mềm: Đóng cửa sổ đen hoặc nhấn Ctrl+C

=============================================
BACKUP DỮ LIỆU
=============================================

Database được lưu tại: dist-portable/data/dev.db

Để backup:
1. Copy file "data/dev.db" ra nơi khác
2. Giữ file backup này an toàn

Để restore:
1. Tắt phần mềm (đóng cửa sổ đen)
2. Thay thế file "data/dev.db" bằng file backup
3. Chạy lại START.bat

=============================================
XỬ LÝ LỖI
=============================================

LỖI: "Cannot find module..."
→ Giải pháp: Xóa thư mục "app/node_modules" và chạy lại START.bat

LỖI: "Port 4000 đã được sử dụng"
→ Giải pháp: Tắt các ứng dụng khác đang dùng port 4000

LỖI: "Database locked"
→ Giải pháp: Đóng tất cả cửa sổ phần mềm và chạy lại

LỖI: "The table does not exist in the current database"
→ Giải pháp: 
   1. Tắt server (đóng cửa sổ đen)
   2. Chạy file "RESET-DB.bat" để tạo lại database
   3. Hoặc chạy "MIGRATE.bat" để cập nhật schema

LỖI: "Không thấy dữ liệu nào"
→ Giải pháp:
   1. Tắt server
   2. Chạy "RESET-DB.bat" để reset và seed dữ liệu mẫu
   3. Chạy lại START.bat

=============================================
HỖ TRỢ KỸ THUẬT
